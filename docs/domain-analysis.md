# Domain Analysis

Предметною областю курсового проєкту є діяльність студії танцю та фітнесу. Студія надає послуги для дітей, підлітків та дорослих. Для ефективної організації роботи студії необхідно вести облік клієнтів, тренерів, робітників, танцювальних груп, стилів, абонементів, локацій та розкладу занять.

Основними учасниками процесів у студії є клієнти, тренери, директор та адміністратор. Клієнти записуються до студії та відвідують заняття у певних танцювальних групах, одній чи декількох. Кожна група має прив'язаного тренера, власний стиль танцю, рівень підготовки, вартість (абонемент) та розклад занять. Заняття відбуваються у визначений час і можуть повторюватися відповідно до розкладу.

Директор студії відповідає за організацію роботи системи: створення танцювальних груп, стилів, абонементів, локацій та залів, призначення тренерів, формування розкладу занять та перегляд клієнтів.

Адміністратор студії відповідає за реєстрацію нових клієнтів. Також може переглядати інформацію про групи, клієнтів, тренерів, локації, стилі тощо.

Основними сутностями предметної області є користувачі (адміністратор, директор, клієнт), локація, зал, абонемент та танцювальна група.  
Кожна танцювальна група має певні характеристики, такі як стиль танцю, рівень підготовки та розклад.  
Між сутностями існують певні зв’язки, які визначають структуру системи та дозволяють організувати ефективне управління діяльністю студії.

Автоматизація цих процесів дозволяє спростити управління студією танцю, зменшити кількість помилок при веденні обліку та забезпечити швидкий доступ до необхідної інформації про учнів, викладачів, групи та заняття.
