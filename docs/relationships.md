# Relationships

Основні зв’язки між сутностями студії танцю.

| Сутність A | Сутність B | Тип зв’язку | Коментар |
|------------|------------|-------------|----------|
| Client     | Group      | Many-to-Many | Клієнт може відвідувати кілька груп, група має багато клієнтів |
| Coach      | Group      | One-to-Many  | Один тренер веде кілька груп, кожна група має одного тренера |
| Subscription| Group     | One-to-Many | Кожна група прив’язана до абонемента, один абонемент може бути у кількох групах |
| Location   | Hall       | One-to-Many  | Локація містить кілька залів |
| Client     | Subscription | One-to-One | Кожен клієнт має один активний абонемент |
| Person     | User       | One-to-One   | Кожен користувач має акаунт у системі |
